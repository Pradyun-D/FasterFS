How It Works

TC egress hook — intercepts every packet to MinIO port 9000, records timestamp in BPF map.

TC ingress hook — when response arrives, computes round-trip latency, increments chunk_hotness[key].

Cache promotion — once count > threshold, chunk is copied to local disk. Next read bypasses MinIO entirely.
